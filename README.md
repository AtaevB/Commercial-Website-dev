Graduation project developed during my studies in Computer Science in Moscow 2019-2023. 

The project is a multi-page website for a commercial company with a separate desktop administration tool for managing news content.



\## Features:

\- Multi-page website

\- Custom UI design

\- News/posts stored in JSON

\- Java Swing administration application

\- Administrator authentication via MySQL

\- Adding new posts through the desktop application

\- Image validation before publishing



\## Technologies:

\- HTML

\- CSS

\- JavaScript

\- Java

\- Swing

\- MySQL

\- JDBC

\- Maven

\- JSON



\## Project Structure:

The project consists of a website frontend and a separate Java Swing administration application.

The administration application authenticates administrators against a MySQL database and allows new posts to be added to the website's JSON-based content storage
